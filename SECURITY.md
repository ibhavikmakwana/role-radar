# Security Policy

## Supported Versions
Only the latest release and the `main` branch receive security updates.

## Reporting a Vulnerability
If you discover a security vulnerability or potential privacy issue in RoleRadar, please responsibly disclose it by opening a private security advisory on GitHub or contacting the maintainers directly.

Please do not disclose security vulnerabilities publicly in GitHub issues. We will respond promptly to review and patch any reported issues.
